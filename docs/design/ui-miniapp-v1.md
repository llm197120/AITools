### 1.2 交互说明

| 元素 | 交互 |
|------|------|
| 顶部用户信息 | 点击进入「个人中心/家庭管理」 |
| 九宫格图标 | 点击跳转到对应功能模块 |
| "更多"按钮 | 预留入口，点击展开常用工具/设置页（后续模块扩展时使用） |
| 今日计划 | 点击跳转到计划模块首页 |
| 首次进入 | 自动调用 `wx.login()` 静默登录 |
| 首次使用 | 弹出"用户须知"弹窗 → 功能简介 + 隐私说明 → 点击"知道了"关闭 |

### 6.7 导入规则说明

| 导入方式 | 文件格式 | 解析方式 | AI识别 | 二次确认 |
|----------|----------|----------|--------|----------|
| 微信CSV | .csv | 程序自动解析字段映射 | 可选（分类映射） | ✅ |
| Excel导入 | .xlsx/.xls | 按模板列名匹配 | 可选（非标格式） | ✅ |
| 银行流水 | .pdf/.xlsx/.xls/.csv | AI识别为主 | 推荐开启 | ✅ |

- **标准Excel模板**：管理端提供下载，包含日期、金额、分类、备注、支付方式等列
- **AI识别流程**：上传文件 → 后端解析文本内容 → AI提取结构化数据 → 返回前端 → 用户确认/编辑 → 写入数据库
- **去重规则**：相同日期 + 相同金额 + 相同备注视为重复，确认时标注黄色警告

 └──────────────────────────────┘

## 十三、通用组件池

| 组件名 | 用途 | 说明 |
|--------|------|------|
| `HomeUpload` | 文件上传 | 内置白名单校验、进度条 |
| `HomeCalendar` | 日历组件 | 月历视图、日期标记 |
| `HomeChart` | 统计图表 | 饼图、柱状图、折线图 |
| `HomeOfficeConvert` | Office格式转换 | 文件转换进度展示、目标格式选择 |
| `HomeFileIcon` | 文件类型图标 | 统一管理各格式文件图标 |
| `HomeNetworkBar` | 网络状态提示条 | 断网/恢复时顶部横条，自动监听网络状态 |
| `HomeLoadingBtn` | 异步操作按钮 | 点击后进入loading态（spinner+文案），防重复点击 |
| `HomeSkeleton` | 骨架屏组件 | 支持列表/卡片/图表三种骨架变体，带shimmer扫光动画 |
| `HomeTransition` | 页面过渡容器 | 统一管理页面切换动效（push/fade/slide） |
| `HomeAnimateList` | 列表动画容器 | 列表项逐条从下至上淡入（stagger 80ms/条） |
| `HomeVoiceInput` | 语音输入按钮 | 调用微信语音识别API，将语音转为文字填入输入框 |

**动效设计规范**：

| 动效类型 | 时长 | 说明 |
| ---- | ---- | ---- |
| 页面切换 | 300ms | 使用微信默认 push 动画 |
| 底部弹窗弹出 | 250ms | 从底部 translateY 滑入，spring 缓出 |
| 底部弹窗收起 | 200ms | translateY 滑出，ease-in |
| 按钮反馈 | 150ms | 点击时 scale(0.95) + 颜色过渡 |
| 列表逐项出现 | stagger 80ms/条 | FadeInUp 动画（HomeAnimateList） |
| 饼图/柱状图 | 400ms | 从 0 到目标值动画绘制 |
| 骨架屏 | 1.5s 循环 | 渐变扫光 shimmer（HomeSkeleton） |

> **设计注意事项**（Agent团队审查补充）
>
> 以下事项在实施阶段需重点关注：
>
> 1. **数据库设计**：实施前需补充完整的DDL（建表语句），包括 `homeai_bill_entry` 的 `version` 乐观锁字段
> 2. **并发控制**：账单编辑/文件上传需实现乐观锁或悲观锁机制，防止多成员同时操作冲突
> 3. **内容审核**：菜谱封面图片、做菜视频需接入微信内容安全API或第三方审核服务
> 4. **AES加密**：IV（初始化向量）需每条记录独立生成并存储，密钥定期轮换
> 5. **LibreOffice**：生产环境配置进程池（corresponding to CPU核数），避免单实例并发转换瓶颈
> 6. **API版本**：建议初期即加入 `/v1` 前缀，后续变更增加新版本端点
> 7. **错误码体系**：实施前定义统一的业务错误码枚举（如 10001=文件不存在、10002=权限不足等）
> 8. **性能优化**：AI对话上下文窗口查询需做索引优化，避免全量加载历史消息
> 9. **运营统计**：管理端需增加 DAU、模块使用率、文件存储量等基础运营指标看板
