# 菜谱 Excel 导入说明（主表 + 食材/步骤子表）

> 第 24 轮起支持子表文本列导入

## 接口

- **导出**：`GET /homeai/recipe/exportXls` — 主表字段 + 食材/步骤文本列  
- **导入**：`POST /homeai/recipe/importExcel` — 主表 + 解析食材/步骤写入子表  

## Excel 列

| 列名 | 说明 |
|------|------|
| 菜谱名称 | 必填 |
| 分类ID | 可选，填 `rc_hot` 等 ID 或中文名（热菜/凉菜/汤羹/主食/烘焙/饮品/小食）。导入时会按菜名纠正过粗分类（如粥归主食、××汤归汤羹）。同名菜谱再次导入会覆盖更新，不会新增重复行。 |
| 封面图片地址 | 可选，菜谱封面图 URL（`http(s)://...`、`/upload/...` 相对地址或 `data:image/...`），详见下方 |
| 难度(1-5) | 可选 |
| 用时(分钟) | 可选 |
| 份数 | 可选 |
| 食材(名称\|数量\|单位;...) | 可选，见下方格式 |
| 步骤(分号分隔) | 可选 |
| 小贴士 | 可选 |
| 可见性(private/family/public) | 默认 private |

## 封面图片地址

- 支持填写**外链图片 URL**（`https://...`），导入后直接用于列表/详情展示
- 也支持本站已上传的相对地址（`/upload/...`）或 `data:image/...` 内联图片
- 格式不正确（如随意字符串）时该行导入失败并提示原因

## 食材格式

```text
鸡蛋|2|个;面粉|100|克;盐|1|茶匙
```

- 多条用英文分号 `;` 或换行分隔  
- 每条：`名称|数量|单位`（数量可为小数）  

## 步骤格式

```text
洗净蔬菜;热锅下油;大火翻炒至断生
```

或：

```text
1. 洗净蔬菜
2. 热锅下油
```

（行首序号会自动去掉）

## 建议用法

1. 先在管理端导出一份样例，按列填写后导入  
2. 家庭共享菜谱需同时填 `可见性=family` 与合法 `familyId`（管理端导入走 `applyAdminVisibilityOnSave`）  
3. 大批量封面图推荐用「批量导入封面」入口（见下）

## 批量导入封面（按文件名 / 文件夹匹配）

管理端菜谱页「**批量导入封面**」：

- **选择图片（单张/多选）**：选一张或多张图片，也可选一个 zip
- **选择菜谱文件夹**：选中整个图片目录（含子目录），浏览器会带上相对路径

后端按以下规则匹配菜谱名称并写入封面（同名菜谱全部更新）：

1. 文件名去扩展名 = 菜谱名，如 `红烧肉.jpg`
2. 父目录名 = 菜谱名，如 `红烧肉/cover.jpg`、`红烧肉/1.png`（同菜多图时优先文件名等于菜名，其次 `cover`/`封面`）

- 支持格式：`jpg/jpeg/png/gif/webp/bmp`，单张 ≤10MB（复用上传白名单 + 魔数校验）
- zip 单包 ≤10MB；更大目录请用「选择菜谱文件夹」（逐张上传，不受整包 10MB 限制）
- 返回报表：成功列表（文件名/菜谱名/更新数）与未匹配清单，未匹配不影响其余图片

**接口：** `POST /homeai/recipe/import-covers`（管理端，权限 `homeai:recipe:importExcel`，多文件 `file` 字段；`originalFilename` 可含相对路径）
