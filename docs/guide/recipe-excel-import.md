# 菜谱 Excel 导入说明（主表 + 食材/步骤子表）

> 第 24 轮起支持子表文本列导入

## 接口

- **导出**：`GET /homeai/recipe/exportXls` — 主表字段 + 食材/步骤文本列  
- **导入**：`POST /homeai/recipe/importExcel` — 主表 + 解析食材/步骤写入子表  

## Excel 列

| 列名 | 说明 |
|------|------|
| 菜谱名称 | 必填 |
| 分类ID | 可选，对应 `category` |
| 难度(1-5) | 可选 |
| 用时(分钟) | 可选 |
| 份数 | 可选 |
| 食材(名称\|数量\|单位;...) | 可选，见下方格式 |
| 步骤(分号分隔) | 可选 |
| 小贴士 | 可选 |
| 可见性(private/family/public) | 默认 private |

## 食材格式

```text
鸡蛋|2|个;面粉|100|克;盐|1|茶匙
```

- 多条用英文分号 `;` 或换行分隔  
- 每条：`名称|数量|单位`（数量可为小数）  

## 步骤格式

```text
洗净蔬菜;热锅下油;大火翻炒至断生
```

或：

```text
1. 洗净蔬菜
2. 热锅下油
```

（行首序号会自动去掉）

## 建议用法

1. 先在管理端导出一份样例，按列填写后导入  
2. 家庭共享菜谱需同时填 `可见性=family` 与合法 `familyId`（管理端导入走 `applyAdminVisibilityOnSave`）
