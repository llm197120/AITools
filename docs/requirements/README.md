## 文档分类

- **需求规格说明书（SRS）**：系统整体需求定义
- **功能需求文档（FRD）**：各模块功能需求详述
- **用户故事（User Story）**：按用户视角的需求描述
- **原型文档（Prototype）**：UI 原型相关说明

## 命名规范

`{type}-{module}-v{version}.md`

示例：`srs-ai-chat-v1.0.md`
