## 审查类型

- **设计审查（Design Review）**：架构设计、详细设计的评审记录
- **代码审查（Code Review）**：代码走查记录
- **安全审查（Security Review）**：安全相关审查记录
- **阶段审查（Phase Review）**：各里程碑阶段审查记录
- **合规审查（Compliance Review）**：基于 JeecgBoot 开发规范的合规性审查
