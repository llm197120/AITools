## 一、架构设计文档遗漏项

### A 级（必须补充）

#### A1. 版本号未更新
- `frontmatter` 中版本号仍为 v3，但经过 Office 合并、目录添加等多次重大修改，应升级为 v4
- 文件顶部 `# 家庭AI小工具 - 功能细化文档 v3` 也需同步

#### A2. 通用组件列表与线框图不同步
- 架构文档 `12.2` 节只列出了 3 个组件：`HomeUpload`、`HomeCalendar`、`HomeChart`
- 线框图 `十一、通用组件池` 已增加到 5 个：新增了 `HomeOfficeConvert` 和 `HomeFileIcon`
- 架构文档需同步更新

#### A3. 资料存储 API 缺少"修改文件夹可见性"接口
- 小程序端有"修改可见性"功能，但 API 列表中 `PUT /homeai/storage/folders/{id}` 只标注了"编辑文件夹"，缺少可见性参数的明确说明
- 建议增加独立的 `PATCH /homeai/storage/folders/{id}/visibility` 接口

#### A4. 学习模块缺少文件上传 API
- 学习资料支持上传 PDF/Word/Excel/PPT/图片/视频，但 API 列表中缺少文件上传端点
- 建议增加 `POST /homeai/learn/materials/{id}/upload`

#### A5. 烹饪模块缺少视频相关 API
- 菜谱支持做菜视频，但 API 中只有菜谱 CRUD，没有视频上传/删除的专用端点
- 建议增加 `POST /homeai/recipes/{id}/video` 和 `DELETE /homeai/recipes/{id}/video`

#### A6. 线框图中 AI 对话附件缺少"文件"选项
- 3.3 节附件操作菜单只有"拍照"和"从相册选择"
- 架构文档 `4.2` 节支持"图片/文件上传到对话"，但线框图中缺少通用的"文件选择"入口

#### A7. 缺少"账单编辑"线框图
- 架构文档说"点击可编辑"，但线框图中没有账单编辑页面的示意图

### B 级（建议补充）

#### B1. 缺少"个人中心"页面
- 首页点击用户信息区跳转到"个人中心/家庭管理"，但线框图中只有家庭管理，没有个人中心（修改昵称、头像、手机号等）

#### B2. 账单导入的 AI 识别编辑缺少后端 API
- AI 识别确认页中用户可以编辑单条记录，但 API 列表中没有"更新导入条目"的接口
- 目前只有 `PUT /homeai/bill/entries/{id}`（编辑已入库的账单），缺少对"未确认导入条目"的操作接口

#### B3. 缺少搜索方案的说明
- 资料存储和学习模块都支持搜索，但没有说明搜索引擎方案（数据库 LIKE？Elasticsearch？）
- 建议补充全文索引的技术选型

#### B4. 缺少数据缓存策略
- 账单统计、学习统计等场景在大数据量下性能堪忧
- 仅在账单模块提到"大数据量时可考虑缓存"，不够具体

#### B5. 缺少操作日志/审计日志
- 文件删除、账单修改、权限变更等关键操作没有日志记录
- 安全合规角度建议补充审计日志设计

## 三、优化建议

### D1. Office 转换进度展示优化
- 线框图 4.3 格式转换页展示了"转换进度条"，但架构文档 `4.3` 说的是"异步处理+轮询"
- 建议在架构文档中补充：轮询策略（间隔多久？超时多久？失败重试几次？）

### D2. 家庭管理增加"修改家庭名称"
- 当前 API 没有提供修改家庭名称的接口，建议增加 `PUT /homeai/family`

### D3. 菜谱评分功能
- 架构文档 `4.6` 业务规则提到"后期扩展：评分"，但线框图中星级已是固定显示
- 建议明确：星级是展示还是可评分的？如果是功能需要，增加评分 API

### D4. 账单增加"预算管理"
- 作为家庭财务管理工具，可以考虑增加"月度预算"功能
- 当前概览页只展示收支，没有预算对比

### D5. 资料存储增加"最近使用"视图
- 文件列表目前只有"按文件夹浏览"和"搜索"两种方式
- 建议增加"最近使用"视图，方便快速找到常用文件

### D6. 线框图增加"加载状态"和"空状态"展示
- 大部分页面只展示了"有数据"的状态
- 建议补充：加载中骨架屏、网络错误提示、空数据引导

### D7. 缺少数据备份恢复方案
- 家庭数据（账单、文件、菜谱等）如何备份和恢复？
- 建议补充数据备份策略

### D8. 小程序分包体积估算
- 架构文档 `3.3` 给出分包大小限制（1.5MB / 1.8MB），但没有说明估算依据
- 考虑到 `towxml`/`mp-html` 这类渲染库通常几百 KB，需要确认分包一是否真的能控制在 1.5MB
